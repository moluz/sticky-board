### v0.3 复验清单（约 1 分钟）

1. **刷新页面**（`Ctrl+R` 可能被宿主占用，用 `Ctrl+Shift+R`）。
2. 任务板：
   - 表头下方出现**看板 tab 条**（默认一块板），点 `＋` 新建第二块；
   - **拖动 tab** 可换顺序；**双击 tab** 可重命名（弹输入框）；✕ 删除当前板。
3. **列排序**：拖动列头最左侧 `⠿` 手柄到另一列头上松手，列顺序应变化；刷新后顺序保持。
4. **搜索**：在搜索框输入便签里有的词，约 0.2 秒后只显示匹配项，顶部计数仍是总数；此时拖拽被禁用（预期）。
5. **导入替换**：`⋯` → 导入 JSON（替换）→ 选之前导出的文件 → 二次确认后整份文档被替换（若只是想加内容，用「合并」）。

### v0.4 复验（Delete 快速删除，约 1 分钟）

1. 刷新页面。
2. 便签墙：点一张便签 → 蓝色描边 + 底部出现快捷键提示；按 `Delete` → 便签进回收站（回收站可恢复）。
3. 任务板：点一张卡片 → 描边；按 `Delete` → 卡片进回收站。
4. 双击便签进入编辑，在文本框里按 `Delete` → 只删文字，便签不消失。
5. `Shift+Delete` → 弹确认框，确认后彻底删除。
6. 点空白处或按 `Esc` 取消选择。

若面板空白或报错，把浏览器控制台里 `slot entry crashed` / `Uncaught` 那几行发我。

## 3. 已知限制 / 设计取舍

- **便签正文编辑走 Markdown 行语义**：`- [ ]` / `- [x]` / `-` / `1.` 决定行类型，保存时整段重解析；用鼠标编辑正文会按文本前缀覆盖原行的 `kind`。
- **搜索在客户端过滤**（每次拉全量快照）：500 便签 / 500 卡 × 12 板以内够用；更大规模再迁服务端查询。
- **导入只开放 merge / replace**（UI）；replace 有二次确认，会整体覆盖当前文档。
- **搜索是服务端过滤**：输入防抖 220ms，Host 按 `q` 只回匹配项；搜索期间拖拽被禁用（过滤后的列表算插入位置会错位）。
- **拖拽排序只在未过滤时可用**：看板 tab / 列 / 卡片共用 HTML5 DnD；跨列拖到列头只用于换列顺序，不创建卡片。
- **多窗口并发**：6 秒轮询 + 服务端串行写；不做实时协同，同字段后写覆盖先写。
- **Host 半更新方式**：`install_bundle` 会报 `already-installed`，需先 `remove_bundle` 再装回；重装后 Host 立即生效、Client 需刷新页面。
- **不要用 PowerShell `Get-Content -Raw` + `Set-Content` 改本仓库源文件**：本机编码下会把 UTF-8 中文压成乱码（`lib/route.js` 上踩过一次，已用 `write` 重写）。改文件用编辑器 / write 工具。

| 打开面板后中心区全黑，侧栏图标还在 | 新增的「切换视图/看板时清空选中」`useEffect` 依赖数组写的是 `[view, trashMode, activeBoardId]`，但它位于 `const activeBoardId = …` **之前**。依赖数组在渲染期求值，命中 TDZ → `ReferenceError: Cannot access 'activeBoardId' before initialization` → App 渲染抛错 → slot entry crashed → 面板空白 | 把该 effect（以及 stale-selection effect）移到所有派生变量（`activeBoardId` / `drawerCard`）之后、`if (data === null)` 提前返回之前；并加注释说明顺序约束 |

**教训**：`useEffect` 的 deps 数组是渲染期就求值的表达式，不能引用同一函数体里后面才 `const` 的变量。Hooks 与派生变量的相对顺序必须固定（所有 hooks 都在提前 return 之前）。
